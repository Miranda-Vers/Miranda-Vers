## 🚀 Principais Projetos

### 📊 [AWS-Economic-Analytics](https://github.com/Miranda-Vers/AWS-Economic-Analytics)
**Pipeline ETL Completo de Análise Econômica Brasileira**

Um projeto end-to-end que coleta, processa e visualiza indicadores econômicos do Banco Central do Brasil em dashboards interativos.

```
✨ Features
├── 📥 Extração de dados da API SGS (Banco Central)
├── ⚙️ Transformação com Pandas e cálculo de indicadores
├── ☁️ Upload automático para AWS S3
├── 📊 Dashboard interativo com Streamlit
├── ✅ Testes automáticos com Pytest
└── 🔄 CI/CD com GitHub Actions
```

**Tecnologias:** Python • Pandas • NumPy • AWS S3 • Streamlit • Plotly • SQLite • GitHub Actions

**Indicadores:** Selic • IPCA • Câmbio USD/BRL

### 🔐 Desafio AML - Detecção de Lavagem de Dinheiro *(Privado)*
**Sistema de Detecção de Padrões Fraudulentos com LLM**

Projeto de seleção para estágio desenvolvido em 24 horas, combinando **regras determinísticas** em Pandas com **interpretação de LLM** para detecção de lavagem de dinheiro.

```
🎯 Componentes
├── Nível 1: Notebooks Jupyter com análise exploratória
├── Nível 2: Agente inteligente com ferramentas customizadas
├── Nível 3: Interface conversacional com Streamlit
└── 📊 Análise de concordância entre regras e LLM
```

**Tecnologias:** Python • Pandas • LLM APIs • Streamlit • Jupyter • Análise Estatística
